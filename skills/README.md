# skills/ — backup versionado

⚠️ **Estas não são as skills que o Hermes lê.** A cópia canônica é
`~/.hermes/skills/<nome>/SKILL.md`. Esta pasta é backup versionado, e o fluxo é
de mão única: **home → repo**, com `ferramentas/sincronizar-skills.sh`.

Editar um arquivo daqui não muda o comportamento de nada. Edite em
`~/.hermes/skills/`, rode o sincronizador e commite.

| skill | ferramenta que ela opera |
|---|---|
| `criar-canal-mugen` | `ferramentas/estudio.py` |
| `publicar-canal-mugen` | `ferramentas/publicar.py` |
